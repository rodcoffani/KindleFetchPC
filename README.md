# KindleFetchPC

<a href="https://github.com/rodcoffani/KindleFetchPC"><img src="https://img.shields.io/github/stars/rodcoffani/KindleFetchPC" height="25px"></a>

Simple CLI for downloading books from Anna's Archive directly to your PC.

Original code from <https://github.com/justrals/KindleFetch>

## Using it

1. Run `./kindlefetch/bin/kindlefetch.sh`
2. Manage your desired configuration and URLs from inside the app via submenus (Option 4)
3. Search for your books (Option 1)
